## Key rules and deadlines (TL;DR)

- **No code written before the event.** All code outside open-source libraries must be written at the event. Pre-written code for the idea, or a project tied to an existing company, means disqualification.
- Team size: **1–4**.
- You must take part in **at least one challenge**. You can submit to multiple challenges.
- **Fri 13.11 23:59:** pre-submission (draft project with the challenge you plan to tackle; you can change it later).
- **Sat 14.11 12:00:** submissions open.
- **Sun 15.11 10:00:** final submission deadline. No late submissions. The project must be set from **DRAFT to FINAL**, because drafts are not reviewed.
- Pitch video: **max 2 minutes**, enforced strictly, publicly viewable (YouTube/Vimeo etc.).
- Source code link required. Organizers must be able to access it. **All submissions are MIT-licensed.**
- **Sun 10:30–14:00 live peer review.** The whole team must be present at the venue, or the team is not eligible for the main prize.
- Prizes: main prize €10,000; total pool €100,000.

## Final submission requirements

- Project name, punchline, description
- Challenge(s)
- Technologies used
- 2-minute video pitch (public link)
- Demo and source code links
- Source code publicity setting
- Whether you want to be credited
- Pitch deck (PDF)
- Team members' phone numbers
- Discord usernames

Each partner sets its own judging criteria for its challenge, so check them carefully.

## Evaluation criteria (peer review)

- **Innovation:** Is the idea/concept/prototype new or different compared to others?
- **Impact:** Does it significantly affect society? How much of the affected population does it help?
- **Implementation:** Is it realistic, viable and feasible from all perspectives?

Partners pick the challenge winners and runners-up. Peer review determines the overall **Top 5**. Each Top 5 team gets 3 minutes on stage (mics are cut at time), followed by 3 minutes of questions. A panel of 7 judges then votes. Teams can demo from their own laptop, and the connection is checked beforehand. There's one handheld mic per team. There's no separate practice slot after review ends, so rehearse in advance. Top teams are contacted before the Closing Ceremony.

## Teams and platforms

- **Junction Platform** (hackjunction.app): team formation (Team tab, team codes), partner meetings, project submission and reviewing. Check-in and submissions go through your dashboard. One team member creates the project submission.
- **Discord:** main communication channel. Use `#announcements` for updates, the challenge-specific channels for mentors and `#teambuilding` to find teammates.
- Team building also happens at the venue on Friday after the opening.

- Check-in starts Friday 16:00 on the 2nd floor. After that, the registration team is at event info on the 3rd floor until Friday 23:59.
